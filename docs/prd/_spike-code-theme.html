S1 — light-dark() across the shadow boundary

1. dark page (data-bs-theme=dark) — expect DARK

2. light page (no color-scheme set) — expect LIGHT even under prefers-color-scheme: dark

3. bare page, no theme attribute at all — expect LIGHT under prefers-color-scheme: dark

4. theme="light" inside a dark page — expect LIGHT (override wins)

5. theme="dark" inside a light page — expect DARK (override wins)

6. runtime flip: this one starts light, JS flips the ancestor to dark — expect DARK with no component JS
