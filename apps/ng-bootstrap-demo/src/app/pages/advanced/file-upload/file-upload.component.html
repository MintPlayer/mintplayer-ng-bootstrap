File upload

bs-file-upload is a drop zone over a native file input: drop files on it, click it or use the browse button. Each batch is added to the two-way [(files)] list, reported through (filesDropped) and announced to screen readers. Rows show the name, size and a progress bar you update; an *bsFileUploadFileTemplate="let upload" template replaces a row. With name the input submits its files with a form, no JavaScript needed.
