Accordion

bs-accordion wraps a stack of bs-accordion-tab children and renders Bootstrap's accordion markup itself, from the framework-neutral @mintplayer/ui-core/accordion core. Each tab declares its header with the *bsAccordionTabHeader structural directive; the rest of the tab body is projected below. Set [multi]="true" to allow multiple tabs to stay open simultaneously, or [highlightActiveTab]="true" to visually mark the active tab.

The accordion is built on native <details name> / <summary>, so it stays fully interactive with JavaScript disabled, single-open exclusivity included — and a closed tab's content is removed from the tab order and the accessibility tree by the browser itself. Headers are reachable with Tab and, once focused, ↑ / ↓, Home and End move between them.

Theming

The markup is Bootstrap's own, so Bootstrap's --bs-accordion-* custom properties theme it from page CSS. Bootstrap declares them on every .accordion, so a nested accordion needs its own rule — which is how the dark multi-level example above is styled.
