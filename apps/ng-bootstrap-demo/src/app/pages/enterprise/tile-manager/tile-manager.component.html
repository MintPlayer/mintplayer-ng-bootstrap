Tile manager

Drag a tile by its header to move it; drag a side / bottom / corner grip to resize. The board keeps one layout per column count: rearrange at one width and the other widths keep theirs. Below the stack width the tiles stack in one column. Layouts persist to localStorage.

Keyboard shortcuts
  • Tab — focus the board. Exactly one tile is in the tab order, so Tab again leaves it.
  • ← → ↑ ↓ — focus the previous / next tile in reading order · Home / End — first / last
  • M — move mode: arrows move the tile one cell · R — resize mode: arrows grow or shrink it
  • Enter — commit · Esc — restore the layout from before the mode, or cancel a pointer gesture
