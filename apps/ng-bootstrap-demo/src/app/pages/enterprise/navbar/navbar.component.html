Navbar

bs-navbar renders Bootstrap's navbar markup from the headless @mintplayer/ui-core/navbar core, server-side included. The responsive collapse is a checkbox and every dropdown a native <details>, so the bar works with JavaScript off. Mark the brand with *bsNavbarBrand, group entries in a bs-navbar-nav (align="end" pushes a group to the far edge), and use bs-navbar-item for every entry — directly in a group as a nav-link, or inside a bs-navbar-dropdown as a menu item; the same element adapts to where it is authored. A dropdown's trigger is the *bsNavbarDropdownLabelTemplate template — any HTML (give an icon-only label an aria-label). A custom hamburger glyph is the *bsNavbarToggler template. Toggling the collapse fires (expandedchange).
