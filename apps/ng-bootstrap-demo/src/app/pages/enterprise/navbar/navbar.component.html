Navbar

bs-navbar renders Bootstrap's navbar markup from the headless @mintplayer/ui-core/navbar core, server-side included. The responsive collapse is a checkbox and every dropdown a native <details>, so the bar works with JavaScript off. Mark the brand with *bsNavbarBrand, group entries in a bs-navbar-nav (align="end" pushes a group to the far edge), and use bs-navbar-item for an entry in a group. A dropdown is the same bs-dropdown-menu / bs-dropdown-item pair a standalone dropdown uses: inside a nav group it renders the navbar's <details> disclosure, nested menus become submenus, and its label is the trigger text (the *bsDropdownMenuLabelTemplate template takes any HTML; give an icon-only label an aria-label). Without JavaScript a dropdown also opens while keyboard focus is inside it. A custom hamburger glyph is the *bsNavbarToggler template. Toggling the collapse fires (expandedchange).
