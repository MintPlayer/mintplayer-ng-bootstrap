Timepicker

Pick a time of day. Two-way bind the current Date via [(selectedTime)]; only the hour/minute components are relevant to the picker.

Basic usage

Selected time
{{ selectedTime() | date: 'HH:mm' }}

Angular forms

Template-driven [(ngModel)] and reactive [formControl] both bind through the component's ControlValueAccessor: the value, the disabled state, and touched when focus leaves.
