Each <tr> holds one radio. The attribute form [bsRadioGroup] sits on the <tbody>, a host the page already has; the radios find their group by DI, so they need no wiring. The size cell holds a radio list of its own: the nearest group wins, so picking a size never changes the row selection, and the other way round.
