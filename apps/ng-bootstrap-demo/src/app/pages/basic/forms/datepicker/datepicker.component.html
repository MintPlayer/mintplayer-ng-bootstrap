Datepicker

bs-datepicker is a popover-style date input with two-way [(selectedDate)] binding and an optional [disableDateFn] for blocking specific dates.

Basic usage

The selected date is: {{ selectedDate() | date }}

Angular forms

Template-driven [(ngModel)] and reactive [formControl] both bind through the component's ControlValueAccessor: the value, the disabled state, and touched when focus leaves.
