Dropdown menu (WC)

bs-dropdown-menu is the Angular wrapper around the framework-agnostic <mp-dropdown-menu> web component. The menu, its keyboard navigation (roving tabindex in menu mode), ARIA roles and theme-aware styling all live in the WC. Project <li bsDropdownItem>, <li bsDropdownDivider> and <li bsDropdownHeader> children. Activating an enabled item fires (select) with the item's opaque value.
