Popover

The bsPopover structural directive on an <ng-template> inside an element turns that element into a popover trigger: a click (or Enter / Space) toggles a non-modal dialog beside it, rendered at the end of <body> so no overflow: hidden ancestor clips it. The directive's value is the side — top, bottom, start or end — and it flips when there is no room. bsPopoverTitle is the heading that names the dialog; the template is its body. Escape (focus returns to the trigger), a click outside or tabbing out closes it. The demo below shows all four positions.
