Offcanvas

bs-offcanvas is a slide-in panel anchored to one of the four viewport edges via [position] (start, end, top, bottom). The host owns open/close state via [(open)]. The panel renders at the end of <body>; with [backdrop] (the default) it is modal and traps focus. The content is the body, the *bsOffcanvasHeader slot is the title that names the panel, and any element inside with data-bs-dismiss="offcanvas" closes it. Escape and the backdrop close it too.
