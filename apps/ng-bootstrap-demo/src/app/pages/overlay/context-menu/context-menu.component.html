Context menu

The bsContextMenu structural directive on an <ng-template> inside an element replaces the browser's context menu on that element. A right-click opens the template at the pointer, rendered at the end of <body>; Shift+F10 and the ContextMenu key open it at the element. The template is usually a <bs-dropdown-menu>. Escape, a click elsewhere, scrolling or choosing an item closes it, and focus returns.
