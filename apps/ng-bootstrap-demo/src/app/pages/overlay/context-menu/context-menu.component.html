Context menu

The *bsContextMenu structural directive attaches a custom right-click menu to any host element. Its template projects a <bs-dropdown-menu> (with <li bsDropdownItem> entries), and the overlay is positioned at the pointer. A <bs-has-overlay> placed elsewhere on the page provides the shared overlay container.
