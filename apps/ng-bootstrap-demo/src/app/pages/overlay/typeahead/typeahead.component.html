Typeahead

bs-typeahead is a text input with asynchronous suggestions and free text. A [provider] function supplies the suggestions for a settled term and receives an AbortSignal: when a newer term supersedes a request, the older one is aborted and its answer is never shown. Typing is debounced ([debounceMs], 200 ms) and gated on a minimum length ([minLength], 1). The value is the text, usable with [(ngModel)] or formControlName; (select) delivers the picked item and (submitted) the term on Enter.

This is the first component built on the headless core architecture: an Angular template rendered from a framework-neutral TypeaheadMachine. With JavaScript disabled, the server still renders a real, named input that submits as free text.
